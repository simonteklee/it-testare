TestARN 🧩

Lokal AI-assistent som bara kan IT-test & kvalitetssäkring — gratis, privat, svar på svenska, alltid med källor. Kopplas automatiskt ihop med klassens frågor & svar och en klasschatt (allt försvinner efter 24 h).

🪟 Windows

Öppna PowerShell (Windows-tangenten → skriv "PowerShell" → Enter) och kör:
irm https://raw.githubusercontent.com/simonteklee/testarn/main/install.ps1 | iex
Frågar efter två gratisnycklar — skriptet öppnar sidorna.

🐧 Linux / macOS

Öppna en terminal och kör:
curl -fsSL https://raw.githubusercontent.com/simonteklee/testarn/main/install.sh | bash
Frågar efter två gratisnycklar — skriptet öppnar sidorna.

🔑 Gratisnycklar (2 min)

  • Groq: console.groq.com/keys
  • Google Gemini: aistudio.google.com/apikey
Logga in → "Create API key" → kopiera → klistra in i terminalen.

🔄 Har du redan appen? Uppdatera hit

Två sätt — båda ger dig senaste versionen (klasschatt, klassfrågor i trådar, nytt utseende):
  • Enklast: öppna appen → 💡 tips & dela → 🔄 Uppdatera appen.
  • Eller: kör samma rad som när du installerade igen — den uppdaterar på plats och behåller dina nycklar:
curl -fsSL https://raw.githubusercontent.com/simonteklee/testarn/main/install.sh | bash
Windows: kör PowerShell-raden ovan igen.
