TestARN 🧩

Lokal AI-assistent som bara kan IT-test & kvalitetssäkring — gratis, privat, svar på svenska, alltid med källor. Kopplas automatiskt ihop med gruppens frågor & svar.

🪟 Windows

Öppna PowerShell (Windows-tangenten → skriv "PowerShell" → Enter) och kör:
irm https://raw.githubusercontent.com/simonteklee/it-testare/main/install.ps1 | iex
Frågar efter två gratisnycklar — skriptet öppnar sidorna.

🐧 Linux / macOS

Öppna en terminal och kör:
curl -fsSL https://raw.githubusercontent.com/simonteklee/it-testare/main/install.sh | bash
Frågar efter två gratisnycklar — skriptet öppnar sidorna.

🔑 Gratisnycklar (2 min)

  • Groq: console.groq.com/keys
  • Google Gemini: aistudio.google.com/apikey
Logga in → "Create API key" → kopiera → klistra in i terminalen.
